Kid Learning Portal – Privacy Policy

Effective: 2026-11-27

Applies to: Kid Learning Portal for Android (io.github.truongngoclinh.klp), version 0.2.0 and later. Earlier versions: no cloud backup, nothing sent off the device.

Short version

  • Cloud backup is optional and only for grown-ups. The app works fully without it.
  • If a grown-up turns it on, the child's game progress and game answers are backed up to our server so they can be restored on another device.
  • While backup is on, the app also sends anonymous usage counts that are not linked to anyone.
  • No sign-in: we never ask for a name, email address or any account.
  • Nothing is shared or sold.
  • No ads. No tracking.

What stays on the device

When cloud backup is off: the child's game progress is stored only on the device, in the app's own storage. It is never sent off the device.

Uninstalling the app removes it. A grown-up can also delete it at any time in the app's grown-ups area.

If a grown-up turns on cloud backup

How it works: the app makes a random family code on the device. Anyone with the code can restore the backup on another device, so keep it safe. We store only a one-way scrambled form of the code, which isn't linked to any name, email or other account.

What we receive: the child's progress (stickers, finished days and their dates) and each game round: which game and day, the puzzle shown, the answers the child tapped, how many tries and hints, and when the round started and ended. No names, voice, photos or free text.

Why: to back up, to restore progress and the weekly report on another device, and to show the report to the grown-up.

Where: our server in Tokyo, Japan (Amazon Lightsail), encrypted in transit (HTTPS).

One family code is for one child.

Anonymous usage counts

Only while cloud backup is on: a play session started or finished (with a rough length), a game finished (with how many rounds needed the step-by-step hint), the report opened, an error screen shown.

They carry no family, child or device id, only the day they arrived, so they can't be linked to anyone or deleted per family. Used only to improve the app. Kept 13 months, then deleted. Never sent while cloud backup is off.

Deleting your data

In the app: grown-ups area › Cloud backup › "Delete cloud backup" (everything on our server for this family), or "Delete your child's data" (on this device and in the cloud backup).

By email: write to the contact address below with your family code (we have no other way to find your data). We delete within 30 days.

How long we keep it: until a grown-up deletes it. Server backups are overwritten within 14 days. If the family code is lost on every device, we can't find or return the backup, but the copy on each device stays.

What we do not collect

We never collect:

  • names or email addresses
  • contacts or photos
  • location
  • microphone or audio recordings
  • camera images
  • device identifiers or advertising IDs (AD_ID)
  • crash logs

Third parties

The app has no SDKs for sign-in, ads, analytics or crash reporting.

Momo's voice is recorded clips shipped inside the app; the device's text-to-speech is used only if a clip is missing. The app only gives it Momo's fixed lines, never anything about the child.

Children

Kid Learning Portal is made for children ages 5 and under and 6–8 (Google Play Families).

Cloud backup is behind a grown-ups gate and is meant for parents; the child never sees it. We collect the child's game progress and answers only after a grown-up turns it on, and only to back them up and show the report.

Before a grown-up deletes data in the app, the device asks them to confirm with Face ID, a fingerprint or the device PIN. That check happens on the device, and we receive nothing.

Permissions

The app does not ask for access to location, the microphone, the camera, contacts or storage.

Changes

If a later version adds sign-in or sends any data, this page will be updated before that version is released, and the effective date above will change.
